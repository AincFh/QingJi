# 轻记 QingJi｜真机演示提纲

状态：功能闭环已在最终 Debug APK 上进行真机验证；连续演示视频尚未录制。脚本只用于下一次录制，不是视频验收证据。

## 录制前

- 使用专用演示设备或不含私人流水的测试环境，准备少量合成消费记录；不要把日常真实流水录入视频或公开截图。
- 安装 `docs/acceptance-status.md` 中记录的最终 APK，确认版本和 SHA-256 后开始录制。
- 录屏保留保存反馈、实际筛选结果、删除确认和进程重启过程；演示数据以设备上的真实交互为准，不预置虚构统计画面。

## 连续演示脚本（约 75 秒）

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 00–08 秒 | 展示首页和当月总览 | 首页将月支出、近期趋势、分类占比和最近流水放在同一条浏览路径中。 |
| 08–20 秒 | 点底部中央“记一笔”，录入金额、选择分类、确认日期，保存 | 主操作在底部固定位置；新增表单聚焦金额，并提供保存结果反馈。 |
| 20–30 秒 | 回首页和统计页查看更新 | 汇总、分类占比和趋势从 SQLite 记录重新计算。 |
| 30–42 秒 | 打开账单，输入备注/金额搜索，再叠加分类或月份筛选 | 查询覆盖历史流水；筛选条件组合后仍对应实际结果。 |
| 42–53 秒 | 打开一笔演示记录，修改金额或日期并保存 | 编辑复用同一表单，保存后列表和统计自动更新。 |
| 53–62 秒 | 对另一笔演示记录打开删除确认，再确认 | 删除前明确确认，删除后列表与统计同步变化。 |
| 62–75 秒 | 展示设置主题和金额显示；强停并重启应用，回查记录 | 主题、隐私偏好与本地流水在进程重启后保持。 |

若演示数据不足以展示上月比较或跨月筛选，应先在专用测试环境中补充合成数据，再录最终版本。不要通过剪辑跳过保存结果或删除确认。

## HR 讲解要点

- **产品判断：** 首页用于快速了解消费；账单用于找到一笔支出；统计解释类别结构与时间变化；设置只保留与日常记账直接相关的偏好。
- **交互取舍：** 中央记账操作保持全局可达；新增和编辑复用表单；空结果、保存、删除和放弃修改均有明确状态。
- **原生实现：** Kotlin + Jetpack Compose + Material 3；SQLite 存储支出，金额以整数分计算，本地偏好通过 SharedPreferences 保存。
- **视觉原则：** 暖纸白、深松绿和柿橙作为轻记自己的颜色；借鉴 Apple HIG 的层级、可读性和克制布局，同时保留 Android 导航与系统主题。
- **范围说明：** 当前是本机单人支出记账原型，不宣称支持收入、预算、导出、云同步、账本或 AI 功能。
