# QingJi v6 页面结构与状态蓝图

产品定位：让个人用尽量少的步骤记录日常支出，并可从消费趋势一路点回真实流水。保持四 Tab + 中央记账，所有内容使用本地 SQLite。

| 页面 | 首屏顺序 | 关键操作与状态 |
|---|---|---|
| 首页 | 品牌/月份 → 本月支出主金额与笔数/变化 → 7 日趋势 → 已设置时的紧凑预算进度 → 分类支出 → 最近流水 | 月份切换；趋势点选后显示金额/笔数和“查看流水”；分类可钻取；最近流水打开详情；空月提示直接记账。 |
| 账单 | 标题/日历入口 → 搜索 → 活跃日期/月份/分类筛选 → 日期分组流水 | 日期、分类和关键词 AND 组合；可清除单个或全部条件；搜索无结果与无任何流水使用不同提示；详情返回保留列表筛选。 |
| 统计 | 月份切换 → 本月/上月对比 → 选中的趋势详情 → 单个分类结构与分类列表 | 趋势和分类均显示选择态、金额/笔数/占比，并以明确按钮打开对应流水；避免重复叠放多个相同含义的图表。 |
| 记账/编辑/复制 | 金额输入 → 最近使用分类 → 全部分类 → 日期 → 备注 → 固定保存操作 | 新增默认今天与用户设置的默认分类；复制保留原金额/分类/备注但默认今天，仍能编辑并插入新 id；校验/防重复提交/成功反馈已有流程继续复用。 |
| 详情 | 金额与分类 → 日期/备注 → 复制 → 编辑/删除 | 无备注时不留空行；删除有确认；复制是新增而不是更新源记录。 |
| 日历 | 月份标题/前后切换 → 清晰的月网格 → 选中日期金额、笔数和当日流水入口 | 每天活动状态来自 SQLite；无消费日期为可选的零值；布局在小屏/大字体下仍保持不拥挤。 |
| 预算 | 月份 → 预算值/修改 → 已用、剩余与百分比进度 → 明确状态 | 未设置、零预算、正常、用尽、超支分开；进度不能出现除零或错误绿色；数据按月持久化。 |
| 设置 | 外观与显示 → 记账偏好 → 消费规划 → 数据与存储 → 关于 | 主题系统/浅/深、隐藏金额、默认分类；预算入口；用户手动 SAF 导出/恢复入口。恢复先校验与预览，说明合并规则后再确认。 |

## 统一组件约束

- 延续 `F8F4E9 / 245B43 / DE601C` 品牌 token。浅色偏暖白，深色用有层次的石墨底；不靠对比度不足的橙色小字承载正文。
- 使用现有 `QingJiSpacing`、`QingJiShapes` 和 Material 3 字体层级；数字金额用等宽或 tabular figures（可用时），标题与正文对齐，不因金额长度破坏布局。
- 主要操作一屏可发现；交互目标至少 48dp；日期图表可用文字标签和语义描述；系统字体放大时允许内容滚动，不固定挤压。
- 动画只用于选中态、进度和值变化，短促并服从系统减少动态效果；不使用模糊、玻璃层和大面积渐变制造层级。
- 空/错/加载/保存/删除均用当前实际数据与明确文案。金额隐藏时，同时隐藏画面、图表辅助文字和无障碍描述中的金额。
